# Five Paper Reading Tracks

Soft launch: October 16, 2026. Five mechanism-focused walkthroughs cover the seven collected papers. This first pass consists of source reading and teaching notes. Implementation, local replication, model measurements, and learner effectiveness are untested.

| Track | Start here | Concrete source material to follow |
| --- | --- | --- |
| 1 Fact memory | [Mem0 and Zep](01-FACT-MEMORY.md) | Mem0's dietary-preference illustration, then the conversation-memory benchmark protocols. |
| 2 Evolving playbooks | [ACE](02-PLAYBOOK-ACE.md) | The roommate-payment example embedded in its prompts, labeled separately from measured outcomes. |
| 3 Consolidated skills | [Trace2Skill](03-SKILLS-TRACE2SKILL.md) | The spreadsheet row-deletion patch and its consolidation into structural-edit guidance. |
| 4 Evaluated prompt revisions | [GEPA](04-PROMPT-OPTIMIZATION-GEPA.md) | The PUPA privacy-preserving delegation prompt-evolution example. |
| 5 Memory maintenance | [RecMem and TrustMem](05-CONSOLIDATION-RECMEM-TRUSTMEM.md) | Recurrence-triggered consolidation and source-to-memory distortion examples. |

Each note explains the original task, inputs and outputs, comparisons, mechanism, visible evidence, and limitations. Original examples, prompt illustrations, hypothetical teaching cases, and measured populations are distinguished. No example is a newly executed model run.

Use the [visibility policy](VISIBILITY-POLICY.md) while reading: track knowledge before, incoming evidence, proposed change, actual change, later context, and evaluation. An unavailable intermediate record stays unknown.

A shared workflow could connect these topics later, but their published aggregate scores measure different tasks and cannot rank all five mechanisms against one another. TrustMem also trains a memory updater; reading its examples does not reproduce that training.
